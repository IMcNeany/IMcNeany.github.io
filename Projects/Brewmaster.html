Overview

Brewmaster: Beer Brewing Simulator is a brewing simulation game aimed at beer enthusiasts and fans of cozy games. Players brew beer using real-world ingredients and techniques which then can then use to complete brewing jobs and enter competitions to unlock cosmetics, equipment and earn money.

The goal for Brewmaster was to simulate beer brewing as realistically as possible. I contributed to the development of the brewing simulation, using real-world modelling to simulate how ingredients and the brewing process affects the final beer. I collaborated closely with the technical artist to develop a system to link live feed data from the brewing simulator into a shader created to reflect how the beer was brewed. I also created a scalable data-driven jobs and competition system that allowed designers to add new content without code changes, as well as implemeting it's UI in the two in game magazines. I worked closely with the UI artist to implement a variety of UI including the in-game magazines and the taste card screens that are used to show how a beer is scored. I also added the system to choose beer bottles and glass types to display the created beer. I also assisted with the deployment of builds through Steamworks. Outside of development, I was involved with the marketing campaign, appearing in a video and an TechRadar article and spoke about the game at a Bristol Games Hub meetup.

Contributions

  • Built a system to feed live brewing simulation data into a liquid shader
  • Created a scalable, data-driven jobs and competition system
  • Close collaboration with the UI team to create responsive and interactive UI
