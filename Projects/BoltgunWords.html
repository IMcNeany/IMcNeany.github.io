Warhammer 40,000: Boltgun - Words of Vengeance

Software used:

Unreal 4, Asana

Languages:

C++

Developer:

Auroch Digital

Warhammer 40,000: Boltgun - Words of Vengeance is a fast paced typing game set in the game Warhammer 40,000: Boltgun. You deal damage to the enemies by typing.

I contributed to the development of the game by prototyping and implementing the first iteration of the typing mechanic. This included handling certain input behaviour such as ignoring non-character input e.g. the Space key. I then integrated the typing mechanics with the enemy damage system and the user Interface, to create a gameplay loop and recieve feedback from the input.
