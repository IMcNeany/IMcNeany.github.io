Overview

My 1st JCB - Diggers and Trucks is a collection of six mini-games aimed at children aged 3-6 featuring all ten characters from My 1st JBC range.

I was the sole programmer on this project alongside one artist. The project comprises of six mini-games, each featuring a different game modes: matching pairs, dot to dot, painting, jigsaw puzzle, character creation and shadow matching. Each mini-game was developed from scratch, requiring implementation of a range of different gameplay systems and features. These included a click and drag mechanic for the jigsaw puzzle, a runtime 2D texture flood fill system for the colouring game and randomisated layout to allow matching pairs to be replayable I also had to ensure that the game would run smoothly on both high-end and low-end mobile devices.
