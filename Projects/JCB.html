My 1st JCB - Diggers and Trucks

Software used:

Unity, Toggl

Languages:

C#

Developer:

Mobile Pie for P2 Games

My First JCB- Diggers and Trucks is a series of six mini-games featuring JBC digger characters. It is aimed at children aged 3-6.

I worked as a solo programmer on this project alongside one artist to form the development team. The project comprised of six mini-games,each featuring a different gamemode: matching pairs, dot to dot, painting, jigsaw puzzle, Create and matching a shadow. Each mini-game was developed from scatch, requiring implementation of a range of different gameplay systems and features. These included a click and drag mechanic for the jigsaw puzzle, a runtime 2D texture flood fill system for the colouringgame and randomisation system to create a random replayable matching pairs.

Contributions

  • Close collaboration with the artist
  • Six interactive replayable mini-games
  • Ensure the game would work on a variety of mobile deivces form low-end to high end
