Starship Troopers: Ultimate Bug War!

Software used:

Unreal 5, Visual Studio, PS5 Developer Tools, Xbox Manager, PIX, Perforce, Asana, Notion, Confluence

Languages:

C++,Python

Developer:

Auroch Digital

Based off the 1997 film Starship Troopers, Starship Troopers: Ultimate Bug War! is a first person shooter. The game has a split of human levels (where you fight against bugs) and bug levels (where you fight the humans).

I join the team with a year left of production, which I jumped in making tooling to assist with auto importing of sprites including setup, map checking and converting voice lines to speech with auto import and setup. Towards the end of the project the focus changed towards game stablility and optimisation, which was tackled on a variery of different fronts with profiling each platform and identifying bottlenecks within the GPU and CPU in general gameplay as well as any instesive levels. Once the bottlenecks had been identified steps were made to reduce the bottlenecks.

Contributions

  • Developed dev tools with Python and intergrated as editor tools using Unreal's Python support
  • Diagnosed and fixed defects using debugging techniques
  • Optimisations on all platforms using GPU and CPU profiling
