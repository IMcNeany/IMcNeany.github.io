Overview

Perfect Dark was a reboot of the classic first-person shooter series, following spy Joanna Dark in a near-future action game. The project was cancelled in 2025.

I worked as part of the gadgets team, building a suite of automated tests to cover all of the gadgets' functionality that would be run on every commit to ensure project stability. I was also part of a refactor to get the gadgets production-ready, restructuring existing code and removing redundant code to improve reliability and maintainability as well as updating the gadget to meet the current design specification.

Contributions

  • Refactored gadget code to make it production ready
