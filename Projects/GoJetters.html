Go Jetters Cadet Rescue

Software used:

Playcanvas, Toggl

Languages:

Javascript

Developer:

Mobile Pie

Go Jetters Cadet Rescue features the popular characters from the children's show Go Jetters and is an adventure game aimed at 4-6 year olds that is made up of mini-games.

I joined the project towards the end of production, with in that time I onboarded to the company and learned how to use Playcavnas. I provided quality assurance testing on this project with testing each mini-game, then providing clear and consise steps to reproduce any issues found. Amoung the issues found I was able to use them to familiarise myself with the codebase and help to fix issues.

Contributions

  • Provide quality assurance to identify issues
  • Fixed defects identified from the QA testing
