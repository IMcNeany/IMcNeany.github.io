Overview

Nightingale is an open-world PvE survival crafting game. Players travel through portals between procedurally generated realms to gather resources, craft and build to aid survival.

I was responsible for converting existing Blueprint systems to C++ to improve the performance of the game's UI screens. Converting the systems involved untangling dependencies across multiple classes while focusing on converting one feature at a time and ensuring that changes were implemented without compromising build stability on a large codebase.

Contributions

  • Converted Blueprint systems to C++ for performance gains
  • Kept the build stable while making changes to a large codebase
